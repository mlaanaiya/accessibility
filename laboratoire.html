Laboratoire de correction RGAA

Manipulez des extraits de code pour corriger les problèmes RGAA. Chaque exercice fournit un contexte, des objectifs, une validation automatique, une prévisualisation et un corrigé complet.

Mode d’emploi

Comment procéder

  1. Lire le contexte et les objectifs.
  2. Modifier le code dans la zone éditable.
  3. Utiliser Prévisualiser pour vérifier le rendu dans l’iframe.
  4. Cliquez sur Valider pour exécuter la validation automatique.
  5. Consultez le corrigé pour comparer et comprendre les pratiques recommandées.

Raccourcis clavier

  • Ctrl + Enter — lancer la validation.
  • Ctrl + Shift + P — prévisualiser.
  • Ctrl + Backspace — réinitialiser le code.

Astuce

Testez la navigation clavier dans l’iframe de prévisualisation pour vérifier vos correctifs.

Exercices interactifs

Exercices disponibles : sémantique HTML pas à pas, formulaires avec erreurs, onglets ARIA, menu méga, gestion des annonces live, FocusMonitor sur Angular. D’autres exercices peuvent être ajoutés via app.js.
