Laboratoire d’exercices interactifs

Corrigez des extraits de code HTML, ARIA et Angular pour atteindre la conformité RGAA. Chaque exercice propose un contexte, des objectifs, une validation automatique et des corrigés.

  • Exercices interactifs

Mode d’emploi

  • Chaque carte précise le niveau, le focus RGAA/ARIA et la validation attendue.
  • Rédigez votre correction dans la zone de code puis cliquez sur Exécuter pour visualiser le rendu.
  • Utilisez Valider pour contrôler automatiquement les points essentiels.
  • Consultez le corrigé pour comparer votre solution et comprendre les bonnes pratiques.

Exercices interactifs

Les exercices couvrent la structure sémantique, les formulaires, les tableaux, les composants dynamiques ARIA et l’intégration Angular accessible. Ajoutez vos propres tests en naviguant au clavier dans la prévisualisation.
